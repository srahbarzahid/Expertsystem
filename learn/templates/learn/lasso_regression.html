Lasso Regression

Lasso Regression is a type of linear regression that uses L1 regularization to improve model performance and reduce overfitting. It adds a penalty equal to the absolute value of the coefficients to the loss function. This helps in shrinking some coefficients to zero, which makes Lasso useful for feature selection.

Types of Lasso Regression

  • Standard Lasso Regression: Applies L1 regularization to reduce the size of coefficients and eliminate less important features.
  • Elastic Net: A combination of L1 and L2 regularization, useful when features are highly correlated.

Assumptions of Lasso Regression

  • Linearity: The relationship between input features and target variable is linear.
  • Independence: Observations are independent of each other.
  • Homoscedasticity: The variance of residuals is constant.
  • Normality: Residuals are normally distributed.
  • Feature Scaling: Features should be scaled before applying Lasso because regularization is sensitive to feature magnitude.

Mathematical Formulation

Lasso Regression minimizes the following cost function:

$$ \text{Cost} = \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{n} |\beta_j| $$

Here, \( \lambda \) is the regularization parameter that controls the amount of penalty.

Code

import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import Lasso
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# Generate synthetic data
np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X[:, 0] + np.random.randn(100) * 0.5

# Train-test split
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.7, random_state=42)

# Feature scaling
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Train the model
model = Lasso(alpha=0.1)
model.fit(X_train_scaled, y_train)

# Predictions
y_pred = model.predict(X_test_scaled)

# Plot the results
plt.scatter(X_test, y_test, color='blue', label='Actual')
plt.scatter(X_test, y_pred, color='red', label='Predicted')
plt.xlabel('X')
plt.ylabel('y')
plt.title('Lasso Regression')
plt.legend()
plt.show()
Lasso Regression

Applications

  • Feature Selection: Automatically removes less important features by shrinking coefficients to zero.
  • Finance: Predicting stock prices and economic indicators with many input variables.
  • Healthcare: Selecting important medical features for disease prediction.
  • Marketing: Identifying key factors affecting sales and customer behavior.

Advantages and Limitations

Advantages Limitations
Performs feature selection automatically. Can remove useful features if the regularization is too strong.
Helps reduce overfitting. Requires feature scaling for better performance.
Works well with high-dimensional datasets. May perform poorly when features are highly correlated.

Hierarchical Clustering

Hierarchical clustering is an unsupervised learning technique used to group similar data points into clusters by building a hierarchy (tree-like structure) of clusters. Unlike K-Means, it does not require choosing the number of clusters beforehand. The hierarchy is typically visualized using a dendrogram.

Types of Hierarchical Clustering

  • Agglomerative (Bottom-Up): Starts with each point as its own cluster and repeatedly merges the closest clusters until one cluster remains.
  • Divisive (Top-Down): Starts with all points in one cluster and repeatedly splits the cluster into smaller clusters.

Key Concepts

  • Distance Metric: How we measure similarity (e.g., Euclidean, Manhattan, Cosine).
  • Linkage Criteria: How we measure distance between clusters:
    • Single linkage: Minimum distance between points in two clusters.
    • Complete linkage: Maximum distance between points in two clusters.
    • Average linkage: Average distance between points in two clusters.
    • Ward linkage: Minimizes variance within clusters (very common and effective).

Mathematical Formulation

For two points \(a\) and \(b\), Euclidean distance is:

$$ d(a,b) = \sqrt{\sum_{j=1}^{n}(a_j - b_j)^2} $$

In hierarchical clustering, we repeatedly merge/split clusters based on a chosen linkage rule.

Dendrogram Explanation

A dendrogram shows how clusters are merged step-by-step. The height at which two branches merge indicates the distance between those clusters. By drawing a horizontal cut line, you can decide the number of clusters.

Code

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
from sklearn.cluster import AgglomerativeClustering

# 1) Generate synthetic data
X, _ = make_blobs(n_samples=250, centers=4, cluster_std=1.1, random_state=42)

# 2) Scale features (important for distance-based clustering)
X_scaled = StandardScaler().fit_transform(X)

# 3) Create linkage matrix for dendrogram (Ward method)
Z = linkage(X_scaled, method='ward')

# 4) Plot dendrogram
plt.figure(figsize=(8, 4))
dendrogram(Z)
plt.title("Dendrogram (Hierarchical Clustering)")
plt.xlabel("Data points")
plt.ylabel("Distance")
plt.tight_layout()
plt.show()

# 5) Choose number of clusters using a cut (example: k=4)
k = 4
labels = fcluster(Z, t=k, criterion='maxclust')

# 6) Plot clustered points
plt.figure(figsize=(6, 5))
plt.scatter(X[:, 0], X[:, 1], c=labels, edgecolors="k", s=35)
plt.title(f"Hierarchical Clustering (k={k})")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.tight_layout()

# Save image for website usage
plt.savefig("hierarchical_clustering.png", dpi=300)
plt.show()

# Optional: AgglomerativeClustering directly (sklearn)
model = AgglomerativeClustering(n_clusters=4, linkage='ward')
pred = model.fit_predict(X_scaled)
Hierarchical Clustering (Dendrogram + Clustered Points)

Choosing the Number of Clusters

  • Dendrogram Cut: Draw a horizontal line; the number of vertical lines it cuts equals the number of clusters.
  • Distance Threshold: Merge until a maximum distance is reached.
  • Domain Knowledge: Choose based on the real-world meaning of clusters.

Applications

  • Customer Segmentation: Group customers based on behavior and spending patterns.
  • Document Clustering: Organize articles or news into topics.
  • Image Segmentation: Cluster pixels/features for object grouping.
  • Bioinformatics: Gene/protein similarity grouping and taxonomy.
  • Market Basket Analysis: Group similar products and purchase patterns.

Advantages and Limitations

Advantages Limitations
No need to pre-choose \(k\): Dendrogram helps decide clusters. Slower on large datasets: Can be expensive for big data.
Dendrogram is interpretable: Shows merging structure clearly. Sensitive to scaling: Features must be normalized/standardized.
Flexible: Works with many distance metrics and linkage methods. Greedy merges: Early wrong merges cannot be undone.
Good for exploratory analysis: Helps understand data hierarchy. Noise/outliers can distort cluster structure.

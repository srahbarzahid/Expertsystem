Random Forest

Random Forest is an ensemble learning method that combines multiple decision trees to make more accurate and stable predictions. Instead of relying on a single tree, it builds many trees using random subsets of the data and features, then aggregates their outputs to reduce overfitting and improve generalization. Random Forest can be used for both classification and regression.

How Random Forest Works

  • Bootstrap Sampling (Bagging): Each tree is trained on a random sample (with replacement) of the training dataset.
  • Random Feature Selection: At each split, only a random subset of features is considered, which increases diversity among trees.
  • Aggregation: For classification, the final output is the majority vote. For regression, the final output is the average of all tree predictions.

Prediction Formulation

  • Classification (Majority Vote): $$ \hat{y} = \text{mode}\{T_1(x), T_2(x), \ldots, T_k(x)\} $$
  • Regression (Averaging): $$ \hat{y} = \frac{1}{k}\sum_{j=1}^{k} T_j(x) $$

Key Hyperparameters

  • n_estimators: Number of trees in the forest.
  • max_depth: Maximum depth of each decision tree.
  • max_features: Number of features considered at each split (e.g., "sqrt", "log2").
  • min_samples_split / min_samples_leaf: Controls minimum samples needed to split a node or be a leaf.
  • bootstrap: Whether bootstrap sampling is used.

Advantages of Randomness

The randomness (data sampling + feature sampling) reduces correlation between individual trees. This makes the combined model more robust and less likely to overfit compared to a single decision tree.

Code

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, ConfusionMatrixDisplay

# 1) Create synthetic classification dataset (2 features for easy plotting)
X, y = make_classification(
    n_samples=600,
    n_features=2,
    n_informative=2,
    n_redundant=0,
    n_clusters_per_class=1,
    class_sep=1.2,
    random_state=42
)

# 2) Split dataset
X_train, X_test, y_train, y_test = train_test_split(
    X, y, train_size=0.7, random_state=42
)

# 3) Train Random Forest Classifier
model = RandomForestClassifier(
    n_estimators=200,
    max_depth=None,
    random_state=42
)
model.fit(X_train, y_train)

# 4) Predict and evaluate
y_pred = model.predict(X_test)
acc = accuracy_score(y_test, y_pred)
print("Accuracy:", acc)

# 5) Plot Decision Boundary
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(
    np.linspace(x_min, x_max, 400),
    np.linspace(y_min, y_max, 400)
)

Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)

plt.figure(figsize=(6, 5))
plt.contourf(xx, yy, Z, alpha=0.3)
plt.scatter(X_test[:, 0], X_test[:, 1], c=y_test, edgecolors="k", s=35)
plt.title(f"Random Forest Classification (Accuracy = {acc:.2f})")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.tight_layout()
plt.show()

# 6) Confusion Matrix (optional plot)
ConfusionMatrixDisplay.from_estimator(model, X_test, y_test)
plt.title("Random Forest - Confusion Matrix")
plt.tight_layout()
plt.show()

Feature Importance

Random Forest can estimate how important each feature is based on how much it reduces impurity across all trees. This is useful for interpretation and feature selection.

$$ \text{Importance}(f) = \sum \Delta \text{Impurity contributed by } f \text{ over all splits/trees} $$

Applications

  • Fraud Detection: Detecting suspicious transactions in banking and e-commerce.
  • Healthcare: Disease risk prediction using patient records.
  • Computer Vision: Traditional image classification tasks using engineered features.
  • Customer Analytics: Churn prediction and customer segmentation.
  • Agriculture: Yield prediction based on climate and soil metrics.

Advantages and Limitations

Advantages Limitations
High Accuracy: Strong performance on many datasets. Less Interpretable: Harder to interpret than a single decision tree.
Reduces Overfitting: Averaging many trees improves generalization. Slower Training: More trees require more computation and memory.
Handles Non-Linearity: Captures complex relationships well. Bias in Importance: Standard feature importance can favor high-cardinality features.
Works with Mixed Data: Handles numerical + categorical (after encoding). Large Model Size: Can be heavy to deploy if too many trees.
